# GUI File Packer & Unpacker

A Java Swing-based GUI application for packing multiple files into a single file and unpacking them back into their original files.

## Features

- Pack multiple files into a single file
- Unpack packed files
- Simple Java Swing GUI
- File handling using Java I/O
- Exception handling

## Technologies Used

- Java
- Java Swing
- Java I/O
- Exception Handling
